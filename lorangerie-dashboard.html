Políticas de contraseña

La longitud mínima y los requisitos de caracteres especiales se configuran directo en Supabase, no aquí, para que apliquen de verdad a nivel de autenticación:

Panel de Supabase → Authentication → Policies → Password Requirements

Nota: la caducidad automática de contraseñas (forzar cambio cada X días) no es algo que Supabase soporte de forma nativa por ahora.
